# EasyAuto 🚗💡

## About

**EasyAuto** è una piattaforma web basata su un database di autovetture, progettata per confrontare due modelli in modalità **1v1**.

L’obiettivo del progetto è aiutare l’utente a scegliere l’auto più conveniente e adatta alle proprie esigenze, analizzando aspetti fondamentali come:

- Consumi e costi di carburante  
- Costi di manutenzione ordinaria  
- Aspetti economici generali  
- Confronto diretto tra due veicoli  

---

## Funzionalità principali

- 🔍 Ricerca e selezione di autovetture dal database  
- ⚔️ Confronto tra due modelli (1 vs 1)  
- 📊 Analisi economica basata su dati reali e aggiornati  
- ⛽ Aggiornamento automatico dei prezzi carburante tramite dataset governativi (MIMIT)  
- 🗂️ Sistema di download giornaliero dei file CSV con log automatici  

---

## Aggiornamento dati carburante

Il progetto include uno script Python che scarica ogni giorno alle **08:00** il file ufficiale:

- `MediaRegionaleStradale.csv`

Fonte: Ministero delle Imprese e del Made in Italy (MIMIT)
